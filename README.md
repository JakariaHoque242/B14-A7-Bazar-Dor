# 🛒 বাজার দর (BazarDor)

প্রতিদিনের নিত্যপ্রয়োজনীয় পণ্যের বাজার দর, দামের ওঠানামা এবং বাজারভিত্তিক সঠিক তথ্যের একটি উন্মুক্ত প্ল্যাটফর্ম। 

চাল, ডাল, তেল, সবজি, মাছ, মাংস কিংবা মসলা—দৈনন্দিন জীবনের প্রতিটি পণ্যের নির্ভরযোগ্য বাজারদর এক প্ল্যাটফর্মে সহজে খুঁজে পাওয়ার সুবিধার্থে অ্যাপ্লিকেশনটি তৈরি করা হয়েছে। সাধারণ ক্রেতা যেন বাজারে যাওয়ার আগেই আজকের সঠিক দাম এবং দামের পরিবর্তনের চিত্রটি পরিষ্কারভাবে জানতে পারেন, সেটাই এই প্রজেক্টের মূল উদ্দেশ্য।

## 💡 প্রধান সুবিধাসমূহ (Key Features)

1. **লাইভ প্রাইস টিকার (Live Price Marquee Ticker):**  
   ওয়েবসাইটে প্রবেশ করলেই শীর্ষভাগে একটি নিরবচ্ছিন্ন স্ক্রোলিং স্ট্রিপ দেখা যায়, যেখানে প্রতিটি পণ্যের ইমোজি, নাম, আজকের মূল্য এবং মূল্যের পরিবর্তন শতকরা হারে প্রদর্শিত হয়।

2. **বাজারের ওঠানামার শীর্ষ তালিকা (Top Risers & Fallers):**  
   আজকের বাজারে যেসব পণ্যের দাম সবচেয়ে বেশি বেড়েছে (**আজ দাম বেড়েছে ▲**) এবং যেসব পণ্যের দাম সবচেয়ে বেশি কমেছে (**আজ দাম কমেছে ▼**), সেগুলোর শীর্ষ ৬টি পণ্য হোমপেজে সহজে চোখে পড়ার মতো করে সাজানো।

3. **পূর্ণাঙ্গ ও রেসপন্সিভ পণ্য ক্যাটালগ (All Products Grid):**  
   সকল পণ্য কার্ড আকারে সুসজ্জিত। প্রতিটি কার্ডে স্পষ্ট বাংলা সংখ্যা, পরিমাপের একক (কেজি/লিটার/ডজন) এবং মূল্য পরিবর্তনের রঙিন নির্দেশক যুক্ত। মোবাইল, ট্যাবলেট কিংবা কম্পিউটার—যেকোনো স্ক্রিন সাইজেই এটি সম্পূর্ণ রেসপন্সিভ।

4. **বাজারভিত্তিক তুলনামূলক বিশ্লেষণ ও প্রটেক্টেড রুট (Protected Product Details):**  
   পণ্যের বিস্তারিত তথ্য দেখার ফিচারটি সুরক্ষিত। লগইন করার পর ব্যবহারকারী প্রতিটি পণ্যের সর্বনিম্ন, গড় ও সর্বোচ্চ দাম দেখতে পারেন এবং কারওয়ান বাজার, বাদামতলী, চকবাজারসহ বিভিন্ন বাজারের দামের সরাসরি তুলনা করতে পারেন।

5. **ক্যাটাগরি পেজ ও বাংলা সংখ্যার সঠিক সর্টিং (Category & Numeric Price Sorting):**  
   চাল, ডাল, তেল, সবজি ইত্যাদি প্রতিটি ক্যাটাগরির জন্য রয়েছে আলাদা পেজ। এছাড়া দামের ভিত্তিতে পণ্য সাজানোর জন্য ডিফল্ট, কম থেকে বেশি এবং বেশি থেকে কম অপশন রয়েছে, যা বাংলা সংখ্যার সঠিক সাংখ্যিক মানের ভিত্তিতে নিখুঁতভাবে কাজ করে।

6. **নিরাপদ অথেনটিকেশন ও প্রোফাইল আপডেট (Authentication & Profile Management):**  
   BetterAuth দিয়ে পরিচালিত ইমেইল ও পাসওয়ার্ডের মাধ্যমে স্বাচ্ছন্দ্যে রেজিস্ট্রেশন ও লগইন করা যায়। ব্যবহারকারী নিজের প্রোফাইলে গিয়ে নাম আপডেট করার সুবিধাও উপভোগ করতে পারবেন।

7. **স্কেলিটন লোডার ও ব্যবহারকারী-বান্ধব ৪০৪ পেজ (Smooth UX & 404 Page):**  
   ডাটা লোড হওয়ার সময়ে আধুনিক অ্যানিমেটেড স্কেলিটন প্রদর্শিত হয় এবং ভুল কোনো লিংকে গেলে হোম পেজে ফিরে আসার স্পষ্ট নির্দেশনা সহ একটি সুন্দর ৪০৪ পেজ প্রদর্শিত হয়।

## 🛠️ ব্যবহৃত প্রযুক্তিসমূহ (Technologies Used)

- **Frontend Framework:** Next.js 14 (App Router)
- **Language:** TypeScript & JavaScript
- **Styling:** Tailwind CSS, PostCSS
- **Authentication:** BetterAuth (Email & Password, Google, GitHub)
- **Database:** SQLite / better-sqlite3
- **Icons & Notifications:** Lucide React, React Hot Toast
- **Font:** Google Font (Hind Siliguri)

## 🚀 লোকাল মেশিনে রান করার নিয়ম (Getting Started)

প্রজেক্টটি নিজের কম্পিউটারে রান করতে নিচের ধাপগুলো অনুসরণ করুন:

1. **রিপোজিটরি ক্লোন করুন:**
   ```bash
   git clone https://github.com/JakariaHoque242/B14-A7-Bazar-Dor.git
   cd B14-A7-Bazar-Dor
   ```

2. **প্রয়োজনীয় প্যাকেজ ইনস্টল করুন:**
   ```bash
   npm install
   ```

3. **ডাটাবেজ ও এনভায়রনমেন্ট সেটআপ করুন:**
   রুট ডিরেক্টরিতে একটি `.env.local` ফাইল তৈরি করুন:
   ```env
   BETTER_AUTH_SECRET=your_super_secret_key_here
   BETTER_AUTH_URL=http://localhost:3000
   NEXT_PUBLIC_APP_URL=http://localhost:3000
   ```

4. **ডেভেলপমেন্ট সার্ভার চালু করুন:**
   ```bash
   npm run dev
   ```
   এরপর ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করলেই ওয়েবসাইটটি দেখতে পাবেন।

5. **বিল্ড টেস্ট করুন:**
   ```bash
   npm run build
   ```
